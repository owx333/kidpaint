# KidPaint 童彩乐园

免费的儿童彩绘网站，包含 600 张填色图、背景填色、自由画笔、贴纸、小画展，以及五首自动轮播的背景音乐。

完成创作后，两位品牌小画家会跳出来，伴随彩色烟花和纸屑庆祝。

## 使用

直接打开 `index.html`，或把整个仓库部署到静态网站托管服务。上传时需保留 `assets/`、`music/` 和两张品牌图片。

作品保存在当前设备的浏览器中，可下载为 PNG 图片。背景音乐首次需要点击音符按钮播放，音量由设备控制。

## GitHub Pages

在仓库 Settings → Pages 中选择 Deploy from a branch、main 分支和 /(root)，保存即可。
