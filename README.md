# KidPaint 童彩乐园

免费儿童在线涂色与绘画：https://www.kidpaint.my/ 。

## 精选图库

现有 168 张经授权与视觉审查的本地矢量模板：可爱动物 23、交通工具 23、幻想魔法 25、美食水果 24、边学边涂 30、节日庆典 27。来源为 Printable Coloring Pages，逐张确认 CC0，允许修改、嵌入和再发布，不要求署名。来源标注 AI 辅助创作，本项目不声称这些是手绘原创。

首批从 160 张候选筛选出 97 张，本次另从 151 张候选新增 55 张，总共 168 张；未加入不合格素材凑数量。详见 reports/library-upgrade.md、reports/library-expansion.md、reports/asset-source-review.json 和筛选记录。

assets/curated/manifest.json 记录每张的稳定编号、标题、分类、本地 SVG/PNG 路径、原始来源、创作者说明、许可、核实日期、年龄、难度、源文件 SHA256 与处理说明。黑色轮廓固定，封闭空白区域可填色；图库先显示轻量 PNG，打开预览后才加载矢量。SVG 经过严格元素及属性检查，不接受脚本、事件或外部图像。

主页开始先选择难度，也可从六个分类进入。支持中文与英文标题、分类搜索、年龄与难度筛选、模板预览。旧模板编号继续支持保存作品和画册导入，原有品牌角色不作为已许可的新模板展示。

## 创作与保存

支持区域及背景填色、画笔、彩虹笔、贴纸、撤销、重做、自动保存和署名 PNG 下载。名字只在首页填写。两位品牌 mascot 在完成时庆祝。作品只存在当前设备浏览器，清理数据前请下载或导出 JSON 画册备份。

绘画页优先显示画布，触控小区域辅助、拖动防误填、缩放按刷新帧合并更新。仅保留音乐播放按钮，五首循环，音量跟随设备。气球背景只在主页运行。
