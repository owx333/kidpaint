# KidPaint 童彩乐园

免费的儿童彩绘乐园，包含 600 张填色图、背景填色、自由画笔、彩虹和渐变画笔、可旋转与排列的贴纸，以及五首自动轮播的柔和背景音乐。

## 创作与探索

- 动物森林、海底王国、星空旅行、甜点乐园、彩虹小镇、魔法故事六个主题世界；任务可跳过，没有倒计时。
- 动画新手引导、常用颜色、撤销与重做；单指画画，双指缩放和移动。
- 图画、画笔、贴纸独立控制显示与锁定；可调整贴纸前后和画笔与贴纸顺序。
- 两位品牌 mascot 在完成时跳出来，伴随短暂的烟花与纸屑。
- 大按钮、颜色名称、键盘填色与减少动画选项。

## 作品保护

作品保存在当前设备的浏览器中。画布显示保存状态，首页可恢复上次作品。

小画展可命名、继续修改、下载 PNG，或导出整本 JSON 画册到另一台设备导入。冲突作品保留为副本；导入会先验证文件。请定期导出画册，清理浏览器数据仍会清除本地作品。

## 部署和离线

GitHub Pages 使用 main 分支和仓库根目录；已有 CNAME 域名配置保留。

线上使用时，Service Worker 会缓存首页、脚本、压缩图片和五首 MP3。首次需联网完成缓存，之后可以断网创作和听音乐。Service Worker 不适用于直接打开 file:// 文件。

音乐只保留播放／暂停按键，五首依次循环，音量使用设备音量。浏览器首次需要用户点击播放。

新版实际使用 WebP 和 MP3。原始 PNG/WAV 文件保留作源素材，不会在页面中加载。
