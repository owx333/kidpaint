# KidPaint 童彩乐园

免费的儿童在线涂色与绘画网站：https://www.kidpaint.my/ 。

## 创作

主题模板按简单、中等、困难分类，支持区域与背景填色、画笔、彩虹笔、贴纸、撤销和 PNG 下载。新增 100 个简化卡通角色线稿，加上原有 9 个，共 109 个；三个难度分别为 37、36、36 个。它们是非官方角色主题创作，没有官方合作关系。

图库可搜索角色名称与主题，并直接切换难度。八个主题世界包含恐龙王国与卡通明星。手机版优先展示画布，小区域提供触控辅助，拖动画布时避免误填色。

名字只在首页填写，顶部显示彩色小画家称呼，下载自动署名。完成时显示个性化祝贺、两位 mascot 与短暂烟花，主要操作是下载和画下一幅。左上角品牌标志直接回首页，首页可继续上次作品。

界面移除设置、音效开关、图层控制及复杂贴纸调整。操作音效固定开启，减少动画遵循设备偏好。五首背景音乐依次循环，仅保留播放按钮，音量跟随设备。

## 作品保护

作品自动保存在当前设备的浏览器中，画布显示保存状态。小画展支持继续修改、下载，以及导出和导入 JSON 画册。请定期备份；清理浏览器数据会清除本地作品。

新模板使用独立编号，旧模板仍可解析原线稿，避免已保存的颜色错位。旧作品的贴纸位置与角度保留。

## 访问统计与说明

首页「认识 KidPaint 童彩乐园」底部显示累计浏览、累计访客、今日浏览与今日访客。visit-stats.js 只向不蒜子 API 请求数字，不加载第三方可执行脚本；每次页面加载仅请求一次。统计从服务接入后开始，不能补回历史访问；访客是估算数量。

统计服务会接收网站网址、来源网站及网络请求信息，不发送昵称或作品。失败或离线时显示暂不可用，不伪造数字。折叠说明包含免费学习用途、成人陪伴、本地备份、角色权利归属和反馈入口。

## 部署

GitHub Pages 使用 main 分支和仓库根目录，CNAME 为 www.kidpaint.my。首页包含 SEO 标题、描述、规范网址、分享信息、结构化数据和彩绘盘 favicon；robots.txt 与 sitemap.xml 指向正式首页。

Service Worker 首次联网缓存页面、脚本、品牌图片和五首 MP3，之后可离线创作。访问统计需要联网，不缓存统计 API。
