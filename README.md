# KidPaint 童彩乐园

免费的儿童彩绘乐园，包含 600 张填色图、背景填色、自由画笔、彩虹和渐变画笔、可旋转与排列的贴纸，以及五首自动轮播的柔和背景音乐。

## 创作与探索

- 动物森林、海底王国、星空旅行、甜点乐园、彩虹小镇、魔法故事六个主题世界；任务可跳过，没有倒计时。
- 动画新手引导、常用颜色、撤销与重做；单指画画，双指缩放和移动。
- 图画、画笔、贴纸独立控制显示与锁定；可调整贴纸前后和画笔与贴纸顺序。
- 两位品牌 mascot 在完成时跳出来，伴随短暂的烟花与纸屑。
- 大按钮、颜色名称、键盘填色与减少动画选项。

## 作品保护

作品保存在当前设备的浏览器中。画布显示保存状态，首页可恢复上次作品。

小画展可命名、继续修改、下载 PNG，或导出整本 JSON 画册到另一台设备导入。冲突作品保留为副本；导入会先验证文件。请定期导出画册，清理浏览器数据仍会清除本地作品。

## 部署和离线

GitHub Pages 使用 main 分支和仓库根目录；已有 CNAME 域名配置保留。

线上使用时，Service Worker 会缓存首页、脚本、压缩图片和五首 MP3。首次需联网完成缓存，之后可以断网创作和听音乐。Service Worker 不适用于直接打开 file:// 文件。

音乐只保留播放／暂停按键，五首依次循环，音量使用设备音量。浏览器首次需要用户点击播放。

新版实际使用 WebP 和 MP3。原始 PNG/WAV 文件保留作源素材，不会在页面中加载。

## 搜索与分享

首页提供描述性标题、搜索描述、规范网址、Open Graph/Twitter 分享信息和 WebSite/WebPage/WebApplication 结构化数据。彩绘盘图标包含 SVG、ICO、多尺寸 PNG、Apple touch 和应用图标。

正式网址为 https://www.kidpaint.my/ 。robots.txt 允许抓取，sitemap.xml 只列出真实的首页网址；应用内部画布和主题界面不伪造为独立页面。

可以在 Google Search Console 验证该域名或网址前缀，提交 https://www.kidpaint.my/sitemap.xml 并请求首页编入索引。本站未加入任何虚构评分，也不承诺搜索排名或收录时间。

## 小画家名字与精品画廊

可选昵称仅保存在当前设备。每幅作品可独立填写署名，并决定下载图片是否显示名字；画册备份保留署名。画布采用柔和彩纸样式。

新增 24 幅可点选填色的主题插画，原有 600 幅的编号和保存进度不变。主角矢量插画改编自 Twemoji，图形为 CC BY 4.0；完整来源、改编说明与许可见 art-credits.html 和 assets/art-source/LICENSE-GRAPHICS。包含这些插画的 PNG 下载页脚带来源署名。

## 故事绘本与简洁首页

新增 18 幅原创故事场景模板，分为三个难度，每级六幅。所有区域是可填色矢量图，作品仍可保存、撤销和下载。保留旧模板编号和保存进度。首页主按钮直接进入故事绘本；昵称填写收进可展开区域，顶部显示彩色小画家称呼。

## 简单绘画界面

移除图层显示、锁定和顺序调整栏，以及贴纸大小、旋转、复制和前后顺序调整。画笔使用默认粗细；放大工具与作品署名默认折叠，去掉画布上方任务栏。保留填色、画笔、彩虹笔、贴纸、橡皮、撤销与下载。旧作品中的图层全部显示并可编辑，避免已移除的图层开关让作品无法操作；旧贴纸的位置、尺寸、角度仍保留。

## 自动作品署名

名字只在首页填写。绘画页面已移除作品署名输入及显示名字开关，生成与下载图片自动使用当前首页昵称；未填写则显示通用作品文字。修改首页昵称后会重新生成下载图片，旧的单幅作品设置不会覆盖首页昵称。
